Silnt
Created by: Ponthief
Usage
1. Configure BlindBit scan URL (and optional auth) via the settings button
2. Add a Silent Payment wallet account using a 12-word BIP39 mnemonic
3. Set the block height of your wallet's first transaction (born-at height)
4. Optionally add a Human Readable Address (BIP353 email format)
5. Click Scan Blockchain to fetch UTXOs from your BlindBit instance
6. Wallet balance updates automatically after each scan (unspent UTXOs only)

GET /silnt/api/v1/wallet
