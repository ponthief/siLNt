Verify your download

Every release is signed. Three commands prove the APK you have is the one we built.

Signing key

F061 E3E9 56FC F57F 99D2 FE48 81DC EBD9 74E9 CABE

Thrilla <thrilla@bitaurus.net>

Confirm this fingerprint somewhere other than this page — on GitHub, X or Telegram. Anyone who could serve you a fake APK from thrilla.me could serve a fake key beside it, and the check would pass anyway.

1 · Get the key and checksums

Run this in the folder you downloaded the APK into. (Opening these links in a browser shows the text rather than saving a file — curl avoids that.)

curl -LO https://github.com/ponthief/thrilla/raw/master/thrilla-signing-key.asc curl -LO https://github.com/ponthief/thrilla/raw/master/SHA256SUMS curl -LO https://github.com/ponthief/thrilla/raw/master/SHA256SUMS.asc gpg --import thrilla-signing-key.asc

2 · Verify

gpg --verify SHA256SUMS.asc SHA256SUMS sha256sum --ignore-missing -c SHA256SUMS # macOS has no sha256sum — instead of the line above: # grep ' thrilla.apk$' SHA256SUMS | shasum -a 256 -c -
gpg: Good signature from "Thrilla <thrilla@bitaurus.net>" [unknown] gpg: WARNING: This key is not certified with a trusted signature! Primary key fingerprint: F061 E3E9 56FC F57F 99D2 FE48 81DC EBD9 74E9 CABE thrilla.apk: OK

You want Good signature, a fingerprint matching the one above, and OK. The WARNING is expected and does not mean the signature is bad — it only says you haven't told GPG you personally trust this key, which you don't need to do.

If either command fails, don't install the APK. Delete it, download again on a different network, and check once more. If it fails twice, tell us before installing anything.

Separately, Android checks the APK's own signature on every update, so once Thrilla is installed a build signed by a different key can't replace it. That makes the first install the one worth verifying.
